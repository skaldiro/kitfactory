# Logos

- `kitmunk-tile.svg`: Logo A, the Case (decision 2). Ink case, four ribs in crew blue, mint, yellow and pink, on a flare tile. Use on light grounds, as the app icon source and in store listings. Fixed colors: never recolor.
- `kitmunk-case-reversed.svg`: the same case drawn in flare with ink ribs, no tile. Use on ink grounds only (first-run header), beside the wordmark in mist.
- `scout-mark.svg`: Scout's mark, flare diamond with an ink eye. Not a logo for the company; it marks Scout.

The wordmark is set, not drawn: "kitmunk", lowercase, Archivo 900 at 62.5% width, ink on light and mist on dark. The `Logo` component renders both lockups.
