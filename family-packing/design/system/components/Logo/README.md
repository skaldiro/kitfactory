# Logo

The kitmunk mark and lowercase wordmark: Logo A, the Case.

Two lockups. **tile** (default): the ink case with four crew-colored ribs on a flare tile, for light grounds, the app icon and the store. **reversed**: a flare case with ink ribs and a mist wordmark, for ink grounds (first run). The wordmark is Archivo 900 at 62.5% width, always lowercase. Never recolor the ribs, put the tile on flare, or set the wordmark in another face. Props: `variant`, `size`, `wordmark`.
