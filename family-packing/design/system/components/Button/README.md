# Button

Main, secondary, destructive and on-dark buttons, 56 tall (44 small).

Orange means Scout (decision 29): `scout` only on a button that hands work to Scout or applies its proposal (Plan a trip, Create our packing list, Ask Scout, Apply N changes, Create the list from a past trip, Sort them for me), at most one per screen. Every other main button is `primary` (ink) on light screens and `onDark` (mist) on ink screens. `secondary` for the alternative, `danger` only to confirm a destructive action, `link` for low-weight actions. Labels are verbs in sentence case.
