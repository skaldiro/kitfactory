# Kitmunk

The AI family packing app for iOS and Android. How we build it: [`CLAUDE.md`](CLAUDE.md).

## Open the latest app on your phone

Scan this with the iPhone camera, or with the scanner in Expo Go on Android. It opens the app as it is on `main`, the latest merged version, in [Expo Go](https://expo.dev/go). No Mac needs to be running.

<img src="https://qr.expo.dev/eas-update?projectId=d9327ad3-f3b5-45fe-9615-1d64c6647675&runtimeVersion=exposdk:58.0.0&channel=main" width="220" alt="QR code that opens the latest Kitmunk app in Expo Go">

After the first scan, Kitmunk also shows in Expo Go's list of recently opened projects. If that entry ever shows an older version, scan the code again.

Every pull request also gets its own QR code in a comment, for checking that change before it is merged.

The QR code holds `exp://u.expo.dev/d9327ad3-f3b5-45fe-9615-1d64c6647675?runtime-version=exposdk%3A58.0.0&channel-name=main`. When the Expo SDK changes (today 58), the `58` in both links changes with it.
